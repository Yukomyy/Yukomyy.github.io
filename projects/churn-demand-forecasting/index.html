01 / CONTEXT

Overview & Problem Statement

Project Overview

In subscription businesses, retaining an existing customer is significantly less expensive than acquiring a new one—yet contacting every customer with discounts wastes budget. This study frames churn prediction as a cost-sensitive decision problem rather than a blind leaderboard competition.

Problem Statement

With ~26.5% baseline churn, a naive classifier achieves 73.5% accuracy by predicting nobody churns. Furthermore, black-box predictions without calibrated probabilities cannot be ranked reliably by customer success teams.

02 / DESIGN GOALS

Objectives & Engineering Solution

Key Objectives

  • 01Prevent data leakage by encapsulating all imputation, scaling, and encoding inside a Scikit-Learn `ColumnTransformer` fit strictly on training folds.
  • 02Compare interpretable regularized Logistic Regression against HistGradientBoostingClassifier using ROC-AUC and PR-AUC.
  • 03Select an operating probability threshold based on estimated retention campaign cost vs. customer lifetime value.

Solution Summary

I structured a reproducible modeling pipeline in Python. After exploratory analysis and collinearity checks (VIF), I engineered tenure-normalized spend features, evaluated stratified cross-validation metrics, and calibrated predicted probabilities so accounts can be bucketed into High, Medium, and Low risk tiers.

04 / IMPLEMENTATION

Selected Code & Query Logic

By combining preprocessing and classification in a single `Pipeline`, cross-validation never leaks validation distribution statistics into the training step.

src/train_churn_pipeline.pypython
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_validate

numeric_pipe = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler()),
])

categorical_pipe = Pipeline([
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("ohe", OneHotEncoder(handle_unknown="ignore", drop="if_binary")),
])

preprocessor = ColumnTransformer([
    ("num", numeric_pipe, numeric_features),
    ("cat", categorical_pipe, categorical_features),
])

clf_pipeline = Pipeline([
    ("prep", preprocessor),
    ("model", LogisticRegression(C=0.5, class_weight="balanced", max_iter=1000)),
])

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_validate(
    clf_pipeline, X, y, cv=cv,
    scoring={"roc_auc": "roc_auc", "pr_auc": "average_precision"}
)
05 / ENGINEERING TRADE-OFFS

Challenges & Architectural Decisions

Technical Challenge

Complex ensemble models offered only marginal ROC-AUC gains (~0.01) over regularized Logistic Regression on this tabular structure.

Engineering Decision

Selected calibrated Logistic Regression as the primary recommendation model while keeping Gradient Boosting as a benchmark comparison.

Trade-off Accepted

Trades a fraction of non-linear capacity for transparent odds-ratio coefficients that business stakeholders can audit.

06 / OUTCOMES & RETROSPECTIVE

Results & What I Learned

Verifiable Outcomes

  • ✓Consistent ~0.84 ROC-AUC across 5-fold stratified cross-validation with zero train-test preprocessing leakage.
  • ✓Identified month-to-month contract structure, fiber-optic price sensitivity, and early tenure (<6 months) as primary churn drivers.
  • ✓Produced an exportable scoring script that outputs customer ID, calibrated probability, risk bucket, and top 3 risk factors.
